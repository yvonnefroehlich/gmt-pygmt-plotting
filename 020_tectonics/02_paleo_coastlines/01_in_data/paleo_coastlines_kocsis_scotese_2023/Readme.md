# PaleoMAP PaleoCoastlines DATA

Date: 2023-04-14
Authors: A.T. Kocsis and C.R. Scotese
Licence: CC-BY 4.0

## Description

ESRI vector shapefiles of continental margins and coastlines are included. Continental margins are -1400m isobaths of the PaleoMAP PaleoDEMs (https://www.earthbyte.org/paleodem-resource-scotese-and-wright-2018/). Coastlines are adjusted from the PaleoDEMs to represent maximum transgressive surfaces, as indicated by the stage-level fossil occurences of the Paleobiology Database (https://paleobiodb.org).

The dataset is intended to supplement the journal article describing it. Please cite the journal article if you use the paleocoastline files. This is version 7.2.

## Contents

- `paleocoastlines_v7_shapefiles.zip` - The paleocoastlines in ESRI shapefiles. Directory `CM` includes continental margins, `CS` includes the coastlines.  
- `paleomap_global_plate_model_v19o_r1c.zip` - The "v19o_r1c" version of the paleomap rotation file, with the corresponding partitioning polygons.  
- `paleomap_global_plate_model_v3.zip` - The earlier, "v3" version of the paleomap rotation file with the corresponding partitioning polygons. ([Scotese, 2016](https://www.earthbyte.org/paleomap-paleoatlas-for-gplates/)) 
- `paleomap_political_boundaries_v3.zip` - The earlier, "v3" version of the paleomap poltical/administrative boundaries. ([Scotese, 2016](https://www.earthbyte.org/paleomap-paleoatlas-for-gplates/)) 
- `paleocoastlines_png_equirect.zip` - Equirectangular projection of the plotted paleocoastlines with present-day coastlines. (3600x1800)  
- `paleocoastlines_png_mollweide.zip` - Mollweide projection of the plotted paleocoastlines with present-day coastlines. (3600x1800)  
- `equirectangular.pdf` - Equirectangular projection of the plotted paleocoastlines (vector)  
- `mollweide.pdf` - Mollweide projection of the plotted paleocoastlines (vector)  
- `readme.md` - Readme and change log.
